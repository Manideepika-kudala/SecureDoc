# SecureDoc

SecureDoc is a secure document-sharing platform developed
for the Snovasys Fresher Hiring Challenge 2026 – RISE.

## Problem
Organizations need to share confidential documents
without exposing them to unauthorized users.

## Solution
SecureDoc provides document-level permissions,
secure file storage, access revocation, and
an audit trail.

## User Roles
- Admin
- Owner
- Viewer

## Main Features
- Authentication
- Secure document upload
- Document management
- READ and EDIT permissions
- Permission grant and revocation
- Secure downloads
- Audit logging
- Document search
- Admin dashboard
- Automated security testing
